## Portfolio personal

[**ibaifarina.dev**](http://ibaifarina.dev) **es mi portfolio personal como desarrollador de software y estudiante de Ciencia de Datos.** Lo diseñé y desarrollé desde cero para tener un espacio propio donde presentar quién soy, las tecnologías con las que trabajo y, sobre todo, los proyectos que voy creando.

Quería que fuese algo más que una página con enlaces: buscaba que la propia web demostrara mi forma de entender el desarrollo, combinando una interfaz cuidada, una identidad visual clara y una experiencia fluida e interactiva.

## Diseño y desarrollo

A nivel técnico, desarrollé el proyecto con **Next.js, React, TypeScript y Tailwind CSS**, estructurando la interfaz mediante componentes reutilizables para las distintas partes de la web: proyectos, experiencia, información personal, habilidades y contacto.

El diseño, primero planificado en Figma, está pensado para ser minimalista pero con personalidad, dando bastante importancia a la tipografía, las imágenes, el espaciado y las transiciones entre contenidos.

## Animaciones e interacción

Una parte importante del proyecto es el trabajo de movimiento e interacción. Utilicé **GSAP y ScrollTrigger** para desarrollar animaciones de entrada, efectos ligados al scroll, parallax y revelados progresivos de contenido. También integré **Lenis** para conseguir un desplazamiento más fluido entre las distintas secciones.

Las animaciones están planteadas para acompañar la navegación sin hacer que la web resulte pesada, y además respetan la configuración de reducción de movimiento del dispositivo.

## Sistema de proyectos

El portfolio funciona también como una colección de mis trabajos. Cada proyecto puede tener su propia página con información sobre el objetivo, mi rol, las tecnologías utilizadas, imágenes y enlaces al producto o repositorio.

Para ello desarrollé un sistema de **rutas dinámicas con Next.js**, de forma que los proyectos se generan a partir de una estructura de datos común y puedo incorporar nuevos trabajos fácilmente.

Actualmente muestro proyectos de diferentes áreas, desde **aplicaciones nativas para iOS y macOS hasta productos web**, incluyendo Haze, OmniTrack, Tempo e IB Studio.

También quería poder explicar algunos proyectos con más profundidad y no limitarme a una imagen y unas cuantas tecnologías.

Por eso implementé un sistema que permite añadir **artículos en Markdown a cada proyecto**, donde puedo documentar el proceso de desarrollo, decisiones de diseño, funcionalidades o aspectos técnicos. Estos contenidos se cargan automáticamente en la página correspondiente del proyecto.

## Español e inglés

El portfolio está disponible completamente en **español e inglés**. Implementé un sistema propio de internacionalización que permite cambiar de idioma tanto en la interfaz general como en el contenido específico de los proyectos.

La selección se guarda en el navegador para que el idioma se mantenga al navegar entre distintas páginas.

## Responsive y experiencia de usuario

La web está adaptada a diferentes tamaños de pantalla, con cambios específicos en navegación, estructura y animaciones para dispositivos móviles.

Intenté mantener la misma identidad visual y sensación de calidad tanto en escritorio como en móvil, evitando simplemente reducir la versión desktop.

## Resultado

Este portfolio es uno de los proyectos que mejor representa mi perfil porque reúne varias de las áreas que más me interesan: **desarrollo frontend, UI/UX, animación, producto y atención al detalle**.

Mi objetivo fue que la web no se limitase a decir qué tecnologías conozco, sino que **la propia experiencia del portfolio sirviera como demostración de lo que puedo diseñar y desarrollar**.
