## Un único lugar para todo lo que veo

Omnitrack es un proyecto personal para iOS con el que registrar películas, series y anime. Lo creé mientras aprendía Swift y SwiftUI, utilizando un problema cotidiano como oportunidad para explorar el desarrollo de aplicaciones nativas y el diseño de producto.

La idea nació de la fragmentación entre distintos servicios de seguimiento. Las películas y series suelen estar en una aplicación, el anime en otra, y descubrir qué ver después queda desconectado del historial que ya existe entre esas plataformas.

## Diseñar una experiencia unificada

El principal reto era reunir distintos tipos de contenido sin eliminar los detalles que hacen único a cada uno. Omnitrack los presenta mediante un lenguaje visual coherente, conservando información útil como temporadas, episodios, fechas de estreno y progreso.

La interfaz prioriza la lectura rápida y las acciones sencillas. Las portadas son protagonistas, el estado y el progreso se entienden de un vistazo, y la navegación sigue la forma natural en la que una persona pasa de descubrir algo a guardarlo y continuar viéndolo.

## Trabajar con varias fuentes de datos

La aplicación combina información de cine, televisión y anime procedente de varias API externas. Construir una sola experiencia sobre modelos de datos diferentes exigió normalizar títulos, imágenes, metadatos y progreso en una estructura compartida sin perder los detalles propios de cada fuente.

Utilicé SwiftUI para crear componentes nativos reutilizables e iterar rápidamente sobre las interacciones. El proyecto reforzó mis conocimientos sobre carga asíncrona, gestión de estado, integración de API y las pequeñas decisiones de interfaz que hacen accesible una aplicación con mucho contenido.

## En qué se convirtió el proyecto

Omnitrack pasó de ser un ejercicio de aprendizaje a un concepto de producto definido: una biblioteca tranquila y visual que entiende todo el entretenimiento en pantalla como parte de una misma colección personal. Refleja el equilibrio que busco en mi trabajo: sistemas técnicos complejos que permanecen invisibles detrás de una experiencia sencilla.
